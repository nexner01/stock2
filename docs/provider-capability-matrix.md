# Yahoo Finance 공급원 적합성 기록

- 검증일: 2026-09-16~17 (Asia/Seoul)
- 환경: Windows, Node.js 24.19.0, `yahoo-finance2` 4.0.2
- 방법: `pnpm provider:probe`, `pnpm provider:smoke`, `pnpm provider:smoke:candidate`,
  `pnpm provider:stability`
- 원본 결과: `docs/validation/provider-probe.json`, `docs/validation/provider-smoke.json`,
  `docs/validation/provider-smoke-candidate.json`, `docs/validation/provider-stability.json`

## 심볼과 메타데이터

| 용도             | Yahoo 심볼     | 확인된 거래소/유형  | 통화 | 결과                                 |
| ---------------- | -------------- | ------------------- | ---- | ------------------------------------ |
| KOSPI            | `^KS11`        | KSE / INDEX         | KRW  | 지원                                 |
| KOSDAQ           | `^KQ11`        | KOSDAQ / INDEX      | KRW  | 지원                                 |
| NASDAQ Composite | `^IXIC`        | Nasdaq GIDS / INDEX | USD  | 지원                                 |
| S&P 500          | `^GSPC`        | SNP / INDEX         | USD  | 지원                                 |
| 한국 KRX 예시    | `005930.KS`    | KSC / EQUITY        | KRW  | 지원                                 |
| USD/KRW          | `KRW=X`        | CCY / CURRENCY      | KRW  | 지원, mapper에서 환율 방향 고정 필요 |
| 추천 ETF         | PDD의 9개 심볼 | ETF                 | USD  | 모두 지원                            |

`DBC`는 NYSEArca ETF로 확인됐으며 다른 심볼로 대체하지 않는다.

## 기간·간격

아래 조합은 AAPL과 `005930.KS` 양쪽에서 유효 OHLCV와 조정 종가를 반환했다.

| 제품 기간  | 요청 간격 |           AAPL |      005930.KS | 초기 정책              |
| ---------- | --------: | -------------: | -------------: | ---------------------- |
| 1시간      |       1분 |           지원 |           지원 | 활성                   |
| 1일        |       1분 |           지원 |           지원 | 활성                   |
| 1주        |       5분 |           지원 |           지원 | 활성                   |
| 1개월      |      15분 |           지원 |           지원 | 활성                   |
| 6개월      |     1시간 |           지원 |           지원 | 활성                   |
| 1년        |     1시간 |           지원 |           지원 | 활성                   |

공급원은 요청 시점과 종목별 상장일에 따라 더 짧은 범위를 반환할 수 있다. UI는 실제 시작·종료일을
표시하고 공백을 보간하지 않는다. 조정 종가는 Yahoo 정의에 따라 분할과 배당을 반영하므로 원시 종가와
별도 필드로 보존한다.

## 검색과 종목 식별

| 입력                  | 결과                                  | 정책                                              |
| --------------------- | ------------------------------------- | ------------------------------------------------- |
| `AAPL`                | Apple과 동명 파생 결과 반환           | 거래소·통화와 함께 표시                           |
| `005930`              | `005930.KS`와 암호화폐 파생 결과 반환 | quote type과 거래소로 필터링                      |
| `Samsung Electronics` | `005930.KS` 반환                      | 지원                                              |
| `삼성전자`            | `Invalid Search Query`                | 검증된 한국어 별칭 인덱스 전에는 비지원 사유 표시 |

동일 문자열 결과를 티커만으로 식별하지 않고 `{ symbol, exchange }`로 식별한다. Yahoo의 `exchange` 코드는
내부 거래소 코드로 명시적으로 매핑한다.

## 배치와 2초 부하 측정

quote 요청은 4개, 10개, 20개 심볼 표본에서 모두 요청 수와 같은 결과 수를 반환했다. 공식 최대값은
공개되지 않았으므로 적용 기본값은 PDD와 같은 10개다.

2026-09-17에 공급원 세션 초기화 후 네 그룹을 2초 고정 시각으로 정확히 60초간 다시 실행했다.

| 그룹       | 성공/시도 |     평균 |      p95 | 지연 | 건너뛰기 | HTTP 429 |
| ---------- | --------: | -------: | -------: | ---: | -------: | -------: |
| 주요 지수  |     30/30 | 192.75ms | 277.24ms |    0 |        0 |        0 |
| 인기 종목  |     30/30 | 191.73ms | 347.83ms |    0 |        0 |        0 |
| 관심 종목  |     30/30 | 233.53ms | 352.73ms |    0 |        0 |        0 |
| 포트폴리오 |     30/30 | 371.77ms | 574.11ms |    0 |        0 |        0 |

같은 환경에서 운영 후보인 5초 주기도 정확히 60초간 실행했다. 네 그룹은 각각 12/12회 성공했고 관심
종목은 회차당 2개 배치로 총 24개 배치를 처리했다. 평균/p95는 주요 지수 379.09/494.20ms, 인기 종목
403.63/495.43ms, 관심 종목 417.70/499.56ms, 포트폴리오 751.13/972.45ms였으며 timeout, delayed,
skip과 HTTP 429는 모두 0회였다.

두 주기 모두 1분 합격 조건을 충족했다. 기본 2초 설정을 유지하며 5초는 공급원 환경 변화 시 명시적으로
적용할 수 있는 검증된 후보로 남긴다. 이 결과는 단일 로컬 환경 측정이며 공급원 SLA가 아니다.

## 1시간 안정성 측정

2026-09-17 12:00~13:00 KST에 최대 구성으로 2초 고정 주기를 3,600.004초 실행했다. 주요 지수는
1,798회 중 1,797회 성공했고 5초 timeout 1회(오류율 0.06%), 겹친 회차 skip 2회 뒤 연결 회복 1회를
기록했다. 인기 종목·관심 종목·포트폴리오는 각각 1,800/1,800회 성공했으며 관심 종목은 총 3,600개
배치였다. 모든 그룹의 HTTP 429와 처리되지 않은 예외는 0회였다.

RSS는 79,380,480B에서 188,215,296B로 증가했고 최대 200,527,872B였다. heap은 17,524,648B에서
29,571,360B로 끝났고 최대 71,724,848B였다. 61개 분 단위 표본의 마지막 10분 RSS는 2,420,736B
감소해 지속적인 RSS 상승은 관찰되지 않았다. 단일 실행이므로 장기 SLA나 메모리 누수 부재를 보장하지
않으며, 주요 지수의 timeout·복구 사례는 애플리케이션 상태 머신의 delayed/skip/recovery 경로가 필요한
실측 근거로 유지한다.

## 이용 제한

Yahoo는 데이터 재배포 금지를 명시한다. 현재 결과는 로컬 MVP에만 적합하며 공개 배포 판단 근거가 아니다.
한국거래소·KOSDAQ은 Yahoo 안내상 20분 지연이다. 화면의 `2초 자동 갱신`은 수집 간격이지 시세의
실시간성을 뜻하지 않으므로 데이터 기준 시각과 시장별 지연 안내를 함께 표시한다.
